# ADR-004: Игровой экран

- Статус: принято
- Дата: 2026-11-08

## Контекст

Правила уже живут в `Game.Core`, уровни и каталог спрайтов — в `Game.Config`. Экрану нужно показать ход, не заводя вторую копию правил и не таща превью макета в билд.

## Решение

`GameSession` в `Game.Core` держит `GameState`, выбранного льва и счётчики золота. Клетка принимается, только если она есть среди `RulesEngine.GetTargets` для выбранного льва. `TryExtract` — это `ConfirmExtract`. `Restart` возвращает состояние уровня и снова выбирает льва A.

`Game.View` — тонкие `MonoBehaviour`. `GameScreenPresenter.Show` получает `LevelConfig`, `SpriteCatalog` и `GameSettingsConfig`. После очереди событий экран заново читает `GameState`: анимация не является источником правды. Спрайты экрана берутся из каталога по `SpriteId`. Прямая ссылка на `Assets/Sprites/preview/Game.png` есть только у выключенного `ReferenceOverlay` в сцене `GameDev`: объект дочерний к Stage, тег `EditorOnly`, в префаб не входит.

Холст `Boot` и `GameDev` считает макет от 1080×2160, Match 0.5, Screen Space Camera. В `Boot` это единственное изменение. `StageFitter` вписывает дочерний прямоугольник 1080×2160 целиком и по центру. Поле вокруг Stage залито цветом RGB (0, 14, 25). Клетка квадратная, не больше 176, зазор 8; для поля не 5×5 сторона равна меньшему из двух осей рамки 940. Сетка по центру.

Кнопка EXTRACT постоянная: серая, пока выход не готов, золотая, когда готов. Серый клик трясёт кнопку и не меняет состояние. Любой `ExitAttempted` пульсирует кнопку. Окна победы, поражения и паузы — заглушки.

`MoveDuration` — ход, прыжок и обмен жетонов. `FadeDuration` — появление, исчезновение, шкала тревоги и счётчик. `PopupDuration` — пульсы, тряска и заглушки WIN/LOSE. Пока анимация идёт, закрыты клетки, выбор льва, EXTRACT и пауза.

## Последствия

Смена правил остаётся в `RulesEngine` и покрывается тестами `GameSession`. Экран можно перерисовать, не трогая ядро. Превью макета не попадает в префаб и не тянется в билд ссылкой из него.
