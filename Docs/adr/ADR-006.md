# ADR-006: Каркас приложения

- Статус: принято
- Дата: 2026-11-08

## Контекст

После игрового экрана нужны меню, настройки и правила, общий переход между ними и место для прогресса. Отдельного экрана загрузки нет.

## Решение

Первый экран — Menu. `ScreenManager` в сцене Boot показывает префабы `ScreenId`: Menu, Settings, Rules, SelectLevel, Game. `ShowAsync` по умолчанию кладёт текущий экран в `NavigationStack` и меняет его через чёрный `FadeOverlay`. Первый показ Menu идёт без затемнения. `BackAsync` при пустом стеке ничего не делает.

`PlayerProgress` хранит открытый уровень и баланс в очках. `IProgressStorage` и `ISettingsStorage` живут в `Game.Core`, реализации на `PlayerPrefs` — в `Game.View`. `SettingsService` хранит Music, Sound и Vibration (по умолчанию включены) и сообщает об изменении. В 5A звук и вибрация не применяются.

Кнопка Play открывает уровень 1 сразу и не пишет экран в историю. Экран выбора уровня — пустая точка расширения, его содержимое будет в 5B. `GameDev` остаётся для отладки и убран из Build Settings. `ReferenceOverlay` по-прежнему только в `GameDev`.

Шрифты экрана: Cinzel для заголовков и чисел, Inter для мелких подписей. Цвета темы — `UiTheme`.

## Последствия

С игрового экрана в 5A нельзя вернуться в меню: история пустая. Для повторного просмотра меню сцена Boot запускается заново. Баланс на меню остаётся 0, пока 5B не вызовет `CompleteLevel`.
