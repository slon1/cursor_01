# ADR-010: Выпуск под Android

- Статус: принято
- Дата: 2026-11-10

## Контекст

Игра должна собираться в Android App Bundle и в тестовый APK. Задание просило Android 7.0 (API 24). Редактор 6000.5 поддерживает Android 8.0 (API 26) и новее: более низкий `minSdkVersion` он отвергает сообщением «Minimum supported Android API level is 26 (Android 8.0)».

## Решение

`Tools/Build/Configure Android` выставляет имя Marit King, пакет `com.slon1.maritking`, версию `1.0.0`, bundle version code `1`. Это значения по умолчанию из задания, владелец может сменить их до выпуска. Минимальный API — 26, целевой — Automatic (highest). Скрипты — IL2CPP, архитектура только ARM64. Ориентация только портрет, автоповорот выключен. Сжатие текстур ASTC. Релизный профиль — LZ4HC и App Bundle. Managed stripping — Low. `link.xml` не добавлялся: при Low обрезка не снимает DOTween и UniTask. В `AppBootstrap` частота 60 и `vSyncCount = 0`.

Разрешение `VIBRATE` лежит в `Assets/Plugins/Android/MaritKing.androidlib`. Подпись релиза читается из `keystore.local.json` или переменных `MK_KEYSTORE_PATH`, `MK_KEYSTORE_PASS`, `MK_KEY_ALIAS`, `MK_KEY_PASS`. Пароли в репозиторий и в лог не попадают. Без подписи релизный скрипт останавливается до сборки. Тестовый APK подписывается отладочным ключом Unity.

`StageFitter` вписывает Stage 1080×2160 целиком в `Screen.safeArea` (contain) и пересчитывает вписывание при смене размера. Поле вокруг Stage — RGB (0, 14, 25). `renderOutsideSafeArea` включён, чтобы сцена рисовалась под вырезом, а элементы оставались в safe area.

Кнопка «Назад» приходит как Escape. Решение принимает `BackPolicy` в Game.Core: Menu — выход, Settings, Rules и SelectLevel — назад (сначала закрыть попап выбора уровня), Game — пауза или снятие паузы, победа и поражение — ничего. Переход экранов и анимация хода нажатие гасят. `BackHandler` только исполняет команду.

`OnApplicationPause(true)` и `OnApplicationFocus(false)` пишут `PlayerPrefs` и, если партия идёт без попапа и без конца раунда, открывают паузу. Хранилища прогресса и настроек сами вызывают `PlayerPrefs.Save()`.

`SpriteAndroidPostprocessor` для `Assets/Sprites` выключает Read/Write и mipmaps и ставит Android override: от 1000 px по большей стороне ASTC 6×6, иначе ASTC 4×4, max size 2048. Режим нарезки не меняется.

Сетка поля ограничена 912 px: сторона клетки `min(176, (912 - (N-1) * 8) / N)`.

## Последствия

API 24 заданием не достигается на Unity 6000.5. Релизный AAB появляется только когда владелец даст keystore вне репозитория. Каталог спрайтов держит все текстуры с запуска; оценка памяти после ASTC записана в отчёте фазы 6C.
