# ADR-005: Минимальная добыча и закрытое поле

- Статус: принято
- Дата: 2026-11-08

## Контекст

Выход открывался, как только сундук был открыт и оба льва стояли рядом. На уровнях можно было уйти, не собрав золото. Клетки с предметами могли стартовать открытыми, и добыча сразу была видна.

## Решение

У `LevelData` и `GameState` есть `MinCoins`. `RulesEngine.ExitConditionsMet` дополнительно требует `Gold >= MinCoins`. `LevelData.Validate` отвергает отрицательный `MinCoins` и значение больше числа клеток с золотом. `LevelMapParser.Parse` принимает `minCoins`.

В начале уровня закрыты все клетки, кроме двух стартовых клеток львов. Предметы остаются скрытыми, пока клетка не открыта.

Золото уровня попадает в баланс игрока только при победе. При поражении собранное золото сгорает. В фазе 5A победа на экране ещё не вызывает `PlayerProgress.CompleteLevel`.

## Последствия

Карты трёх уровней переписаны: закрытые клетки и `MinCoins` 2. Старые числа решателя для этих карт больше не действуют. Решатель, которому вручную передали карту с золотом меньше `MinCoins` в обход проверки, возвращает непроходимый результат.
