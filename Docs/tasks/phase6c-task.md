# ФАЗА 6C. Подготовка к выпуску под Android

**Роль:** ты исполнительный программист проекта Unity 6000.5. Архитектор — Claude (проверяет через git, смотрит картинки из репозитория). Устройства у тебя нет: проверки на телефоне делает владелец проекта по чек-листу в конце.
**Ветка:** `phase/6c-android` (от `main` после мерджа `phase/6a-solver`).

**Прочитай перед работой:** `Docs/adr/ADR-004`, `ADR-006`, `ADR-007`, `Docs/TECH_DEBT.md`, `Docs/MANIFEST.csv` (строки категории AppIcon).

**Цель:** проект собирается в Android App Bundle и тестовый APK, учитывает вырез экрана, кнопку «Назад», сворачивание приложения и не раздувает память текстурами.

## Входные данные (значения по умолчанию, владелец проекта может изменить до запуска)
- Название приложения: `Marit King`.
- Package name: `com.slon1.maritking`.
- Версия: `1.0.0`, bundle version code `1`.
- Минимальная версия Android: 7.0 (API 24). Целевая: самая высокая доступная.

## ЧАСТЬ 1. Настройки проекта (скрипт `Tools/Build/Configure Android`, идемпотентно)
- Product name, package name, version, bundle version code по значениям выше.
- Scripting backend IL2CPP, целевая архитектура только ARM64 (ARMv7 выключить), `Build App Bundle` включить. Minimum API 24, Target API: Automatic (highest).
- Ориентация: только портрет (проверь, что остальные выключены, автоповорот выключен).
- Texture compression: ASTC. Compression method для релиза LZ4HC. Managed stripping Low. Если для DOTween или UniTask нужен `link.xml`, добавь его (проверь, нужен ли в IL2CPP-сборке).
- `Application.targetFrameRate = 60` и `QualitySettings.vSyncCount = 0` в `AppBootstrap`.
- Разрешение VIBRATE: убедись, что оно попадает в итоговый манифест; если нет, добавь `Assets/Plugins/Android/AndroidManifest.xml` с `<uses-permission android:name="android.permission.VIBRATE" />`.
- `.gitignore`: `*.keystore`, `*.jks`, `keystore.local.json`, `Builds/`, `Library/` (если ещё нет).

## ЧАСТЬ 2. Иконки
- Адаптивная иконка: слои из спрайтов манифеста `AppIcon_Foreground` и `AppIcon_Background` (`Assets/Sprites/icon_foreground.png`, `icon_background.png`). Если по виду `icon_background` на самом деле не подходит как фон (в манифесте стоит пометка про `push_large_icon.png`), не угадывай: приложи в отчёт картинку составной иконки из каждого варианта и спроси.
- Старый формат (legacy) и круглая иконка: собери составную из тех же слоёв редакторским скриптом (192×192) или оставь автогенерацию Unity, если она корректна.
- Скрипт `Tools/Build/Apply Icons` идемпотентный. В отчёт приложи картинку итоговой иконки.

## ЧАСТЬ 3. Память и размер текстур
- Все полноэкранные фоны (1080×2160) на Android должны быть сжаты (ASTC 6×6), остальные спрайты ASTC 4×4 или 6×6 по размеру; Read/Write выключен, mipmaps выключены. Реализуй `AssetPostprocessor` в `Game.Editor`, который ставит Android override для всех текстур в `Assets/Sprites` (по размеру: от 1000 пикселей по большей стороне 6×6, меньше 4×4, max size 2048). Не менять режим нарезки.
- Отчёт: суммарный размер текстур в памяти до и после (оценка по формату), 10 самых больших текстур. Помни, что `SpriteCatalog` держит ссылки на все спрайты, то есть все текстуры в памяти с запуска: если сумма больше 150 МБ, предложи решение (например, отдельные каталоги по экранам или Addressables) и запиши в `TECH_DEBT`, не внедряй.

## ЧАСТЬ 4. Вырез экрана и системные панели
- `StageFitter` вписывает Stage по принципу contain в `Screen.safeArea` (а не во весь экран). Пересчитывается при смене `Screen.safeArea` и разрешения. Вне Stage остаётся заливка (0, 14, 25).
- Проверка в редакторе через Device Simulator на 2–3 устройствах с вырезом и без; скриншоты в `Docs/reports/phase6c/`.

## ЧАСТЬ 5. Кнопка «Назад» (Android Back приходит как `Keyboard.current.escapeKey` в Input System)
Класс `BackHandler` (тонкий, логика решения вынесена в Core и тестируется):
- Menu: выход из приложения (`Application.Quit()`).
- Settings, Rules, SelectLevel: `ScreenManager.BackAsync()`; если открыт попап выбора уровня, сначала закрыть его.
- Game: если открыта пауза, Resume; если играем, открыть паузу; если открыты победа или поражение, ничего.
- Во время перехода экранов (`_busy`) и анимации хода нажатия игнорировать.
Тесты на чистую логику выбора действия по состоянию (Core).

## ЧАСТЬ 6. Жизненный цикл
- `OnApplicationPause(true)` и `OnApplicationFocus(false)`: `PlayerPrefs.Save()`; в игре при активной партии (нет попапа, не конец партии) открыть паузу.
- `PlayerPrefsProgressStorage` и `PlayerPrefsSettingsStorage` после записи вызывают `PlayerPrefs.Save()`.

## ЧАСТЬ 7. Сборка
- `Tools/Build/Build Android Bundle (Release)` и `Tools/Build/Build Android APK (Development)`: вывод в `Builds/` (в git не попадает). Подпись релиза читается из `keystore.local.json` (путь, алиас, пароли) или переменных окружения `MK_KEYSTORE_PATH`, `MK_KEYSTORE_PASS`, `MK_KEY_ALIAS`, `MK_KEY_PASS`. Если данных нет, скрипт останавливается с ясным сообщением (пароли в репозиторий не коммитить и в логи не писать). APK для разработки использует debug-подпись.
- Отчёт о размере сборки (AAB и APK) и о предупреждениях сборки.
- Если сборку нельзя выполнить без Android SDK/NDK на машине, сделай все настройки и скрипты и напиши в отчёте, что именно не удалось запустить.

## Чек-лист устройства (для владельца проекта, `Docs/ANDROID_CHECKLIST.md`)
1. Установить APK на телефон, запуск без вылета.
2. Меню, настройки, правила, выбор уровня открываются, переходы с затемнением плавные.
3. Тапы по клеткам точные, подсветка видна, прохождение уровня 1 от начала до победы.
4. Кнопка/жест «Назад»: Menu выходит, Settings, Rules, SelectLevel возвращают, Game открывает паузу, пауза закрывается.
5. Свернуть и развернуть игру в середине партии: открывается пауза, прогресс не потерян.
6. Вибрация на ловушке и при поражении работает; при выключенной в настройках не срабатывает.
7. Телефон с вырезом или жестовой навигацией: верхняя панель и нижняя область не перекрывают элементы игры.
8. Частота кадров ощущается плавной (60 fps), телефон не греется.
9. Закрыть приложение, открыть заново: баланс и открытые уровни сохранились.
10. Иконка приложения выглядит правильно (круглая и квадратная маски).
