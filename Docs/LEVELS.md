# Уровни

Поле читается сверху вниз и слева направо. `minT` — наименьший порог тревоги, при котором уровень проходим: пик тревоги на самой спокойной победе плюс 1. У всех уровней `JumpCost` 2, `GateBreakCost` 3, `TrapCost` 4.
