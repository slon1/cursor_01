# Фаза 2.1

Ветка: `phase/2-core`, продолжение после `phase-2-done`.

## Сделано

- Ход на закрытый сундук открывает клетку и принимается. Лев остаётся, тревога и `JumpCost` не меняются. Ход на открытый сундук по-прежнему `TargetIsChest` без событий.
- `Accepted = false` больше не меняет состояние. Закрытая решётка льва А принимается: `CellOpened`, затем `GateBlocked`. Открытая решётка льва А отклоняется с пустым списком событий.
- Если сундук открывается, пока его клетка закрыта, сначала идёт `CellOpened`, потом `ChestOpened`.
- `ExitConditionsMet` требует открытую клетку выхода. `ConfirmExtract` при закрытом выходе ничего не делает.
- `LionsSwapped` получил `Initiator` и `IsJump`.
- `Cell.IsOpen` и `Cell.Item` уже были с `internal set`, конструктор `Cell(bool, ItemType)` уже был. `LevelData` и `LevelBuilder` пишут клетки только через конструктор, правки им не понадобились.
- `Docs/adr/ADR-002.md` обновлён. Тесты закрытого и открытого сундука, закрытой решётки, сундука между львами, закрытого выхода и полей обмена обновлены.
- EditMode: 76 тестов зелёные. Консоль Unity: 0 ошибок и 0 предупреждений.

## Решение

Архитектор подтвердил: закрытый сундук ход показывает. Отказ оставлен только там, где состояние не меняется.
