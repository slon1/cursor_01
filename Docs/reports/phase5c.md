# Фаза 5C. Забрать сундук

Сундук больше не открывается сам. Его забирает ход на уже открытую клетку, если второй лев стоит рядом по стороне. Лев встаёт на клетку, сундук исчезает и золота не даёт. Закрытая клетка с сундуком только открывается, лев остаётся, прыжок в этом ходе тревогу не поднимает. Прыжок, которым сундук забирается, стоит обычный `JumpCost`. Пока сундук на поле, EXTRACT серая. Выход готов, когда сундук забран, клетка выхода открыта, оба льва рядом с выходом и золота хватает.

Порядок событий забирания: `LionMoved`, `ChestTaken`, затем `AlarmChanged`, если тревога изменилась, затем `GameLost`, если достигнут порог. Подсветка берётся из `GetTargets`: открытый сундук входит в цели только при смежном партнёре.

Быстрые EditMode-тесты: 113 из 113, 1,4 с. Явный тест решателя не запускался. Консоль после прохода уровня 1: 0 ошибок, 0 предупреждений.
