# Фаза 6A. Решатель и подсветка

Проверка карт снова занимает секунды и возвращает путь. Ручные проходы уровней 1–3 зафиксированы тестами. Подсветка рисуется поверх предмета.

`FindAny` ищет любую победу. Оценка хода `f = g + 3h`, но дерево раскрывается в глубину: дети одного узла сортируются по `f`, при равенстве сохраняется порядок генерации, и сначала исчерпывается лучший ребёнок. Глобальная очередь с той же оценкой на этих картах не укладывается в секунды. Пока сундук не взят, `h` не видит выход и вычищает плато, где львы уже рядом с сундуком, а наборы открытых клеток разные. На уровне 1 это больше 100 тысяч состояний за две секунды и всё ещё без победы. Глубина с тем же `f` находит победу. Для `FindAny` ключ не содержит тревогу: хранится наименьшая тревога достижения, более высокая отбрасывается, более низкая открывает ключ снова.

`Shortest` — поиск в ширину по ключу вместе с тревогой, до первой победы. Эвристика и отсечение по тревоге для него не используются. `AlarmAtWin` — тревога найденного пути. `MinPeakAlarm` по-прежнему не считается. `TrySolve` остаётся обёрткой `Shortest` со старым пределом 2 000 000 состояний. Лимит состояний или времени даёт `Truncated` без исключения.

Ключ — маска открытых клеток, маска убранных предметов, координаты львов и `ChestTaken`. Поле до 64 клеток. Перед ходом доска собирается из ключа и `LevelData`. `Clone` в цикле поиска нет. Ход делает только `RulesEngine`.

Замер в редакторе, `FindAny` с пределом 5 000 000 состояний и 60 с, `Shortest` с теми же пределами:

`FindAny` на каждом уровне быстрее пяти секунд. Самый долгий — уровень 2, 2,7 с. Узкое место прежней глобальной очереди снято порядком обхода; отдельного узкого места, которое не уложилось бы в пять секунд, не осталось. Пути `FindAny` длинные: поиск берёт первую глубокую ветку, а не кратчайший проход. Их тревога — тревога этого пути, не 0 / 5 / 0 ручного прохода.

`Shortest` на трёх уровнях возвращает `Truncated`: за 60 с разобрано около 2,0–2,4 миллиона состояний, победа не встретилась. Это не ошибка карты. Компактный ключ ускорил шаг (раньше 2 миллиона состояний занимали 5–6 минут), но число состояний поиска в ширину не уменьшил. Меню `Tools/Levels/Verify All Levels (Shortest)` пишет в консоль `Truncated` и не бросает исключение. `Tools/Levels/Verify All Levels` вызывает `FindAny`.

Ручные проходы, не минимумы решателя: уровень 1 — 17 ходов, тревога 0; уровень 2 — 14 ходов, тревога 5; уровень 3 — 18 ходов, тревога 0. Каждый ход принят, `TryExtract` принят, статус `Won`.

`EveryAuthoredLevel_IsSolvable` вызывает `FindAny` и по-прежнему помечен как явный. Отдельный прогон этого теста: 1 из 1, 2,10 с, все три уровня проходимы и без `Truncated`. В обычном прогоне те же уровни проверяет `FindAny_AuthoredLevels_PathsWin`: путь проигрывается через `GameSession` до победы, тревога совпадает с `AlarmAtWin`. Этот тест занял 2,29 с.

Быстрые EditMode-тесты: 129 из 129, 3,55 с. Явные тесты в этот прогон не входили. Консоль: 0 ошибок, 0 предупреждений.

Подсветка внутри клетки стоит после предмета: основа, предмет, подсветка, затем жетоны. Прозрачность 0,5. Снимки 1080×2160:
