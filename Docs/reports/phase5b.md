# Фаза 5B. Выбор уровня и итог партии

Ветка `phase/5b-select-popups`. Play открывает выбор уровня. Победа пишет прогресс сразу. Поражение прогресс не трогает.

## Поток

Menu → Play → SelectLevel (меню остаётся в истории). Узел открыт, если уровень открыт прогрессом и у него есть конфиг. Сейчас это уровни 1–3. Узлы 4–10 закрыты: тап трясёт узел и не открывает окно. Тап по затемнению закрывает только окно выбора. ENTER открывает уровень.

Пауза блокирует поле. Resume продолжает, Restart начинает заново, Main Menu очищает историю и возвращает в меню. Затемнение паузу, победу и поражение не закрывает.

Победа: `Finished` → `GameRunController` → `RunFlow.Finish` → `CompleteLevel` и запись в `PlayerPrefs`. Next есть, только если следующий конфиг существует. Level Select с победы и поражения возвращает к выбору, а назад с него ведёт в меню. Повторная победа снова добавляет золото. Поражение золото не сохраняет.

Вибрация: `Handheld.Vibrate` на ловушку и отдельно на поражение, только на Android и iOS. В редакторе вызов пустой. Music и Sound по-прежнему только хранятся.

## Проверка

EditMode: 107 тестов, 0 падений, 1.3 с. Медленный решатель в прогон не входил.

В Play Mode, Game view 1080×2160: Boot → Menu → Play → уровень 1 → победа (9 ходов, тревога 6, 200 очков) → Next → уровень 2 → поражение (тревога 9) → Try Again → пауза → Main Menu. После этого в `PlayerPrefs` остались уровень 2 и баланс 200: поражение запись не затёрло. Меню показало BEST HAUL 200. Снимок выбора с открытыми 1–3 сделан после ещё одной записи победы на уровне 2 через тот же `RunFlow.Finish` (баланс 400). Тап по затемнению закрыл окно, тап по закрытому узлу 4 окно не открыл.

Консоль редактора после прогона: 0 ошибок, 0 предупреждений. Ключи `PlayerPrefs` после проверки удалены, следующий запуск начинается с уровня 1 и баланса 0.
