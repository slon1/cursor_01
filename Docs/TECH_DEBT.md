# Технический долг

Сюда записываются осознанные компромиссы, которые нужно закрыть позже.

- AssemblyMarker в Game.View удалить, когда в сборке появится реальный код (фаза 4).
- `IsExternalInit` в Game.Core нужен, чтобы record собирались без ссылки на UnityEngine. Убрать, когда профиль сборки начнёт содержать этот тип сам.
- SampleScene не используется, удалить.
- SpriteCatalog.TryGet делает линейный поиск по списку; когда View начнёт часто обращаться к каталогу (фаза 4), заменить на лениво строящийся словарь.
- 83 спрайта в Assets/Sprites остаются в режиме Multiple с единственной нарезкой (хрупко при переэкспорте картинки); перевести в Single одним проходом, если импорт манифеста снова упадёт на нарезке.
