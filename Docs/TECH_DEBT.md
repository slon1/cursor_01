# Технический долг

Сюда записываются осознанные компромиссы, которые нужно закрыть позже.

- `IsExternalInit` в Game.Core нужен, чтобы record собирались без ссылки на UnityEngine. Убрать, когда профиль сборки начнёт содержать этот тип сам.
- SampleScene не используется, удалить.
- 83 спрайта в Assets/Sprites остаются в режиме Multiple с единственной нарезкой (хрупко при переэкспорте картинки); перевести в Single одним проходом, если импорт манифеста снова упадёт на нарезке.
- Опечатка «TARGET REACHERD» запечена в спрайтах победы и поражения. Число после точки уже рисуется отдельно. Когда владелец уберёт запечённый текст, подпись Target добавляется отдельно.
- Music и Sound только сохраняются. Звук не играет.
- `LevelSolver.MinAlarmAtWin` — тревога при победе за минимум ходов, а не минимально возможная тревога. Позже добавить `MinPeakAlarm` (фаза 6). Проверка карт вручную: `Tools/Levels/Verify All Levels`.
- Ускорить `LevelSolver`: компактный ключ состояния вместо строки и ход без `Clone`, например через откат. Это фаза 6. Обычный прогон тестов больше не ждёт решатель: полный поиск помечен `[Explicit]` и `[Category("Slow")]`. После правила «забрать сундук» `Tools/Levels/Verify All Levels` на уровнях 1–3 упирается в лимит 2 000 000 состояний и победу не печатает. Карты при этом проходимы: конкретные пути есть в отчёте фазы 5C.
