# Технический долг

Сюда записываются осознанные компромиссы, которые нужно закрыть позже.

- `IsExternalInit` в Game.Core нужен, чтобы record собирались без ссылки на UnityEngine. Убрать, когда профиль сборки начнёт содержать этот тип сам.
- SampleScene не используется, удалить.
- 83 спрайта в Assets/Sprites остаются в режиме Multiple с единственной нарезкой (хрупко при переэкспорте картинки); перевести в Single одним проходом, если импорт манифеста снова упадёт на нарезке.
- Опечатка «TARGET REACHERD» запечена в спрайтах победы и поражения. Число после точки уже рисуется отдельно. Когда владелец уберёт запечённый текст, подпись Target добавляется отдельно.
- Эффекты и фон играет `SoundManager`: Sound глушит эффекты, Music включает `background.mp3`.
- Имя Marit King, пакет `com.slon1.maritking`, версия `1.0.0` и bundle version code `1` — значения по умолчанию из задания. Владелец может сменить их до выпуска.
- `SpriteCatalog` держит все спрайты с запуска. Оценка 86 текстур: RGBA 191 482 444 байт (182,6 МБ), после ASTC 22 314 224 байт (21,3 МБ). Порог 150 МБ не превышен, отдельные каталоги не нужны.
- Скорость решателя: открытость клеток в ключе больше не хранится. `AlarmAtWin` по-прежнему тревога одного найденного пути.
- `MinPeakAlarm` закрыт: это `MinSolvableThreshold - 1`. Пик — тревога после хода, уже после сброса рубильником. `AlarmAtWin` по-прежнему тревога одного найденного пути.
